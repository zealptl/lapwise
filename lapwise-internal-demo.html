05One lap of a request

Lights out to flag

1
Authenticate
Client signs in against the Cognito user pool (email + password, no self-signup) and receives a JWT.
2
Authorize at the edge
API Gateway's JWT authorizer validates the token on every route — only /healthz, /docs and /openapi.json are public.
3
Compute on demand
Lambda cold-starts the Docker image; Mangum translates the event and FastAPI routes it. Pydantic models validate everything in and out.
4
Fetch & shape
The service layer calls OpenF1 over httpx, then aggregates — pace deltas, DNF rates, pit-stop consistency — before returning typed JSON.

07LapwiseF1Agent

The race engineer

Ask it a fantasy question in plain English. It calls Lapwise analysis endpoints as tools, weighs DNF risk against upside, and always answers with three scenarios:

Best team
Maximum expected points within the £100M budget, every pick justified by a data signal.
Value picks
Under-priced drivers below £10M whose pace data outruns their price tag.
Risk-tolerant
High-variance picks with real upside — risk acknowledged, signal cited.

08Agent security — two M2M hops

No open radio

1
User → Runtime
The user calls the agent with their own Cognito JWT. Identity stays user-scoped at the front door.
2
Runtime → Gateway · client A
The agent exchanges machine-to-machine client A credentials (pulled from Secrets Manager, cached per cold start) for a token to reach its tool gateway.
3
Gateway → Lapwise API · client B
The gateway uses a second M2M client to call the API. The JWT authorizer accepts both audiences — so each hop rotates independently, zero downtime.
4
Tools from the spec
The gateway builds its tool catalog straight from /openapi.json — new analysis endpoint, new agent tool. No glue code.

12Deployment — two pit crews

Two-stop strategy

cdk deploy
API stack — infra/
Build — Docker image from service/, pushed to ECR
Synth — CloudFormation template from TypeScript
Ship — Lambda + API Gateway + Cognito + logs, one stack, outputs the API URL
agentcore deploy
Agent stack — agent/
Package — CodeZip of the ADK app, separate CDK stack
Wire — gateway URL injected as env var, scoped IAM auto-generated
Isolate — deploys & rolls back independently; the API never notices
